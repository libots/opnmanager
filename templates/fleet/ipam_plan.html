Addressing: Address Plan

One plan for the fleet. Each logical interface gets an address template such as 10.x.40.1/21 or x:x:x:40::1/64; each firewall's site prefix fills in the x parts. Observed addresses come from Interfaces: Overview (refresh it to compare). The manager doesn't change interface addresses on the firewalls; OPNsense has no API for that.
