Addressing: Address Plan

One plan for the fleet. Each logical interface gets the firewall's own address on it as a template, such as 10.x.40.1/21 or x:x:x:40::1/64; each firewall's site prefix fills in the x parts. The comparison uses what the firewalls reported on their last pull. Review & push addresses (per firewall, OPNsense 26.7 or later) sets the planned addresses on interfaces configured as static; interfaces using Identity association get their planned ULA as a virtual IP.
