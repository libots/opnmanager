Addressing: DNS Options

DNS bases hold a value for each site: DNS servers (such as each site's AD domain controllers) or domains (such as each site's suffix). A base can have a default for every site (templates like 10.x.10.5 resolve with each site's prefix) and its own value at some sites. Preference lists put bases in order: this.ad is this site's, others.ad every other site's in the fleet order, ad both, Cloud.ad one site's, and router the firewall on the interface. DHCP scopes that use a list hand out DNS servers (option 6) and the domain search list (option 119) in that order at every site.
