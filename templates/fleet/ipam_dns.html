Addressing: DNS Order

Write the order once and let each site fill it in. Each site has its own DNS servers (such as its AD domain controllers) and domain; a DNS preference list puts them in order, for example site, site:Cloud, other-sites, router: this site's servers first, then a named site's, then every other site's in the fleet order, then the firewall itself. DHCP scopes that use a list hand out DNS servers (option 6) and the domain search list (option 119) in that order at every site.
