Addressing: Push Interface Addresses

{{ firewall.name }} · Read from the firewall just now. Checked interfaces get the planned firewall address; then the interfaces are applied and read back. Only interfaces already set to a static address are changed.

This changes interface addresses on a live firewall. Devices on these networks lose their gateway until their own addresses, DHCP ranges and reservations follow the new plan, and rules, VIPs and services that name the old addresses stop matching. There is no automatic rollback: if something goes wrong, fix it under Interfaces on the firewall. The address the manager connects to is never changed here. Nothing runs while the firewall has unapplied interface edits.
